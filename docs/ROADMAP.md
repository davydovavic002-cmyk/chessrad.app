# ChessRad — Roadmap

## Реализовано

- Напоминания (колокольчик + email при SMTP)
- Трансляция лидеров на лобби
- Лиги и командные турниры
- WebRTC видео в study / group-study
- **PGN в study** — загрузка партии на доску
- **Слабые темы** — из журнала → пазлы по теме
- **Достижения / бейджи** — профиль и лобби
- **Турниры live** — обновление списка по сокету, таймер до старта
- **Родительский кабинет** — `/parent`, привязка email в журнале
- **История группового класса** — сохранение в журнал учеников
- **Опрос в группе** — «Кто нашёл тактику?»
- **Prod deploy** — `docs/DEPLOY.md`, `ecosystem.config.cjs`
- **E2E smoke** — Playwright (`npm run test:e2e`)
- **PWA** — vite-plugin-pwa, offline shell + кэш статики

## Проверка после обновления

См. **[QA-CHECKLIST.md](./QA-CHECKLIST.md)** — 10 быстрых задач (~15 мин).

## Дальше (низкий приоритет)

- Полноценные E2E с логином и study/homework/group flows
- Offline puzzle bank (sync puzzles to IndexedDB)
- Rate limit на group sockets
- Nodemailer мониторинг доставки

## Групповое занятие — реализовано

1. Упражнение → раздать → мозaика
2. Разбор / трансляция решения
3. Мини-турнир с возвратом в класс
4. Опрос и сохранение в журнал
