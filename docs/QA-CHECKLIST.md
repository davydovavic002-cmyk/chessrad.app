# ChessRad — 10 быстрых проверок

После деплоя или крупного обновления пройдите за ~15 минут:

1. **Логин** — войти как ученик и учитель; `AUTH_BYPASS=false` в prod.
2. **Study + PGN** — создать комнату, вставить PGN («Загрузить PGN»), проверить вкладку с ходами.
3. **Домашка** — выдать из study, выполнить на `/homework`, бейдж «Первая домашка» в профиле.
4. **Журнал + слабые темы** — в журнале «не пройдено» → «Потренировать» → пазлы с темой.
5. **Групповой класс** — упражнение, опрос «Кто нашёл?», «Сохранить в журнал».
6. **Турниры live** — список `/tournaments`: счётчик игроков, таймер до старта, регистрация.
7. **Родитель** — `POST /api/parent/link` (учитель), вход parent → `/parent`.
8. **Напоминания** — колокольчик за час до урока/турнира; email при настроенном SMTP.
9. **PWA** — установить приложение, открыть `/puzzle` offline (кэш UI; задачи нужна сеть).
10. **Лобби** — бейджи, spotlight турниров, календарь ученика.

**E2E (опционально):** `npm run test:e2e` из корня проекта.
